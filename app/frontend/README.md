# OPG-AsymmetryNet Frontend

React + Vite + Tailwind CSS frontend for the OPG-AsymmetryNet clinical decision support system.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env` and set `VITE_API_URL` to your backend URL.

```
VITE_API_URL=http://localhost:8000
```
